# BidCheck — 나라장터 입찰 분석 웹

접속 주소: **https://bidcheck.midiro-i2l.workers.dev**

기존에 Claude 프로젝트와 엑셀로 손으로 하던 작업(공고 확인 → 제안요청서·공고문 HWP 내려받기 → 분석 → 엑셀 정리)을
웹 하나로 옮겼습니다. 모든 기록은 DB(Cloudflare D1)에 쌓이므로 엑셀 파일이 필요 없습니다.

## 업무 흐름

1. **공고 검색** — 구분·키워드·기관·공고일로 조회 → 마감 상태·입찰마감일·금액으로 거르고, 공고명·기관·금액·마감일 열을 눌러 오름/내림차순 정렬.
   공고를 누르면 **웹 안에서 상세 내용**(기관·담당자, 계약방식, 금액, 일정, 면허·지역 제한)과 **첨부파일 다운로드** 버튼이 보입니다.
   자주 보는 조건은 🔖로 저장하면 매일 아침 7:30 자동 검색해 대시보드에 **추천 신규 공고**로 보여 줍니다.
2. **관심 등록** 또는 **적합도 분석** — 분석을 누르면 나라장터 첨부(제안요청서·공고문 HWP/PDF)를 자동으로 가져와 읽고
   회사 정보·서류와 대조해 **결과보고서**를 만들고 저장합니다. 공고 상태는 자동으로 ‘결과서’가 됩니다.
3. **입찰 관리** — 관심 / 결과서 / 입찰진행 / 제출·결과대기 / 종료 탭, ‘결과서 있는 공고만’, ‘내 담당만’ 필터, 열 정렬.
4. **제안서 초안 작성** — 결과서가 있는 공고에서 버튼 한 번으로 작성. 제안요청서 목차·요구사항을 모두 반영하고
   표·다이어그램(구성도·조직도·일정 간트)·차트, 요구사항 대응표, 추가 제언을 넣습니다. Word·인쇄(PDF)·MD 로 저장.
5. 상태 변경(입찰진행 → 제출 → 낙찰/탈락/미참여), 담당자 지정, 팀 의견, 서류 준비 체크, 일정 캘린더, 히스토리.

## 계정

- 처음 접속하면 **관리자 계정 만들기** 화면이 나옵니다.
- 관리자는 [설정 → 사용자 관리]에서 직원 계정을 등록합니다. 임시 비밀번호가 메일로 가고, 첫 로그인 때 새 비밀번호로 바꿉니다.
- 비밀번호를 잊으면 로그인 화면의 **비밀번호 찾기**로 등록된 이메일에 임시 비밀번호가 발송됩니다.
  메일 발송은 [설정]에 Resend 키를 넣어야 동작합니다(무료 하루 100통). 키가 없으면 관리자가 [비밀번호 초기화]로 임시 비밀번호를 확인해 전달합니다.

## 키 설정 ([설정] 화면, 관리자)

| 항목 | 받는 곳 |
| --- | --- |
| 나라장터 키 | data.go.kr → `조달청_나라장터 입찰공고정보서비스` 활용신청 → 일반 인증키(Decoding) |
| Claude API 키 | console.anthropic.com → API Keys (결제 크레딧 필요, Claude 앱 구독과 별도) |
| 메일(Resend) 키 | resend.com → API Keys. 자체 도메인을 인증하면 누구에게나 발송 가능 |

## 구조

```
bidcheck/
├─ worker/            Cloudflare Worker API (Hono)
│  ├─ index.ts        라우팅, 매일 아침 자동 검색(cron)
│  ├─ auth.ts         로그인·세션·사용자 관리·임시 비밀번호
│  ├─ notices.ts      나라장터 검색·상세·첨부 다운로드·저장 검색·추천
│  ├─ bids.ts         입찰·첨부·결과보고서·제안서·의견
│  ├─ company.ts      회사 정보·서류, 대시보드, 일정, 설정
│  ├─ claude.ts       Claude 분석·제안서 프롬프트
│  └─ storage.ts      파일 저장 (기본 D1, 선택 R2)
├─ shared/types.ts    공용 타입, 결과보고서 스키마
├─ migrations/        D1 스키마
└─ src/               React 화면
```

- 첨부파일과 회사 서류도 D1 에 1.8MB 조각으로 저장합니다(R2 불필요). 무료 플랜 DB당 500MB.
- HWP·HWPX·DOCX·XLSX 는 브라우저에서 텍스트를 추출하고, PDF 는 원본을 그대로 Claude 에 전달합니다.
  배포용(읽기전용)·암호 HWP 는 한글에서 PDF 로 저장해 올리세요.
- Cloudflare Workers **무료 플랜은 요청당 CPU 10ms 제한**이 있어, 큰 PDF 분석이나 제안서 작성이 중간에 끊길 수 있습니다.
  그럴 땐 Workers Paid(월 5달러)로 올리면 해결됩니다.

## 배포

`main` 또는 작업 브랜치에 push 하면 GitHub Actions(`.github/workflows/deploy-bidcheck.yml`)가
D1 생성·마이그레이션·빌드·배포를 자동으로 합니다. 저장소 Secrets 에 `CLOUDFLARE_API_TOKEN`(Workers Scripts·D1 편집 권한),
`CLOUDFLARE_ACCOUNT_ID` 가 필요합니다.

## 로컬 개발

```bash
npm install
npm run db:migrate:local
npm run dev        # http://localhost:5173
```
